  ```

  ```

- The daemon bundle was nevertheless emitted (tsc emits despite
  the error): `apps/daemon/dist/` = **2,355 files** incl.
  `dist/cli.js` — the exact dist §4 booted.
- Site analysis (read-only): in `SpawnedAgentProcess`'s constructor,
  `const signal = proc.signalCode ?? null;` takes bun-types'
  `Subprocess.signalCode`, typed `number | Signals | null` in
  `@types/bun` 1.4.4, and line 530 assigns it to the class field
  `signalCode`, declared `string | null`. This is R3b code passing
  through `tsc` for the first time (R3b verified by live probes,
  which all passed; the mismatch is type-level only — at runtime
  `proc.signalCode` yields a signal name or null). NOT fixed here;
  it is the follow-up stream's one-line headline.
